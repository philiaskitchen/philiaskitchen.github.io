# Philia的廚房料理

台式點心與法式甜點的個人食譜網站。網址：https://philiaskitchen.com

## 怎麼新增一道食譜

1. 到 [Pages CMS](https://app.pagescms.org) 用 GitHub 帳號登入，選這個儲存庫。
2. 點「食譜」→「新增」，照表單填寫，上傳去背插圖。
3. 按 Save。GitHub 會自動重新發佈，大約 1–2 分鐘後網站就會更新。

## 檔案在哪裡

- `src/content/recipes/`：每道食譜一個 `.md` 檔
- `public/images/recipes/`：食譜插圖（去背 PNG／WebP）
- `src/styles/global.css`：顏色和字體（照 Design System 的 tokens）
- `public/images/ui/`：手繪元件（遮陽棚、花邊按鈕、標籤…）
